This is a simple web app to help you study the countries of the world. You can search for information about a country, or do a quiz to test your memory of flags, countries and capitals.

Data about the countries has been assembled from following sources:

  • RestCountries: the bulk of the country data in JSON format
  • Flagicons: flags in SVG format
  • Wikipedia: country maps

While the following sites and data are not used directly, they are also relevant for users of this app:

  • Flags that look alike
  • Country GDP data
